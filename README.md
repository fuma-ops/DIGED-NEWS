# DIGED News
Chaîne YouTube Shorts d'actualité expliquée simplement (monde, géopolitique, économie, sport, tendances US).
- `PROCESS.md` : la procédure complète (à suivre par la routine automatique).
- `pipeline/` : détection, voix off (edge-tts), alignement des sous-titres, montage, contrôle de prononciation, musique.
- `templates/overlay.html` : gabarit d'habillage ; `examples/` : 3 Shorts réalisés (Iran, Beaver Moon, UE).
- `brand/` : photo de profil, bannière.
Dépendances : ffmpeg, Playwright (Chromium), /usr/bin/python3 avec faster-whisper, numpy, edge-tts.
